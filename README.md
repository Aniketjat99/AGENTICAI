# 🤖 Autonomous AI Research Agent

An AI-powered research assistant that performs real-time web search and generates structured summaries using free LLM models.

---

## 🚀 Features

* 🌐 Real-time web search using Tavily API
* 🤖 AI-powered summarization using HuggingFace (FLAN-T5)
* 💻 CLI + 🌐 Web UI (Streamlit)
* 📄 Automatic report generation and storage
* ⚡ Fast and lightweight (No paid APIs required)

---

## 🧠 Tech Stack

* Python
* Streamlit
* HuggingFace Transformers
* Tavily API
* Agentic AI Concepts

## ⚙️ Installation

```bash
git clone https://github.com/Aniketjat99/AGENTICAI.git
cd AGENTICAI
pip install -r requirements.txt
```

---

## 🔑 Setup Environment Variables

Create a `.env` file and add:

```
TAVILY_API_KEY=your_api_key_here
```

---

## ▶️ Run Application

### CLI Version:

```bash
py -3.11 main.py
```

### Web UI:

```bash
py -3.11 -m streamlit run app.py
```
